## 📖 About

**Nature of Indonesia** is a personal front-end project created as part of my journey learning React.

The goal of this project is to build an educational website that introduces Indonesia's rich biodiversity while improving my understanding of component-based development, reusable UI, and modern front-end practices.

---

## ✨ Features

- 🌿 Flora Education
- 🐅 Fauna Education
- 🖼 Modern Landing Page
- 🎴 Reusable Card Components
- 📱 Responsive Layout *(Work in Progress)*

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Flowrith/indonesia-nature-website.git
```

Move into the project

```bash
cd indonesia-nature-website
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
